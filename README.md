# Ethereum and Cosmos Governance Audit Evidence Pack

An evidence pack auditing the on-chain governance of two live systems —
ENS DAO (Ethereum Mainnet) and Cosmos Hub (cosmoshub-4) — against the
extended governance-audit framework v1.1.0. It extends the
Multi-Protocol Governance Audit Framework v1.0.0
(https://github.com/araupooo/multi-protocol-governance-audit-framework)
with four new checks (concentration, upgrade authority, time-bounded
veto, snapshot reproducibility) and measured concentration and
participation from dated snapshots.

## Layout

- `framework/spec.md` — framework specification, control catalogue, threat model
- `framework/scoring-rubric.md` — rubric detail (pass / partial / fail criteria)
- `framework/rubric.json` — machine-readable rubric v1.1.0 (27 checks; the engine's source of truth)
- `audit-engine/audit.py` — Python 3 stdlib-only audit engine (offline)
- `protocols/*.json` — one verified profile per system (parameters + citations)
- `protocols/*.md` — one rendered audit report per system (generated, committed)
- `assessments/ethereum-ens.md`, `assessments/cosmos-hub.md` — the two worked assessments
- `docs/methodology.md` — extended methodology + scoring rubric + limitations
- `docs/gap-list.md` — what v1.0.0 lacked and what v1.1.0 adds
- `docs/evidence-index.md` — claims → source / script / output
- `docs/index.html` — rendered findings page (generated)
- `claims.md` — claim-to-evidence index (every claim maps to a file + output)
- `findings.md` — all severity-ranked findings (generated from engine output)
- `citations.md` — every primary source used, with URL and what it establishes
- `evidence.json` — machine-readable summary (systems, scores, findings counts)
- `scripts/measure.py` — computes all measurements from snapshots only (no network)
- `scripts/run_all.sh` — measure + engine + checks + digests
- `scripts/clean_reproduce.sh` — re-run from a fresh copy, require byte-identical outputs
- `scripts/verify_digests.sh` — verify SHA256SUMS
- `snapshots/` — dated raw source snapshots with a manifest (dates + block heights)
- `outputs/run1/` — unedited run logs, score JSONs, audit reports, measurements
- `outputs/run2-clean/` — clean-reproduction outputs (byte-identical to run1)

## How to run

```bash
python3 scripts/measure.py       # measurements from snapshots/ -> outputs/
bash scripts/run_all.sh          # engine -> outputs/run1, checks, digests
bash scripts/clean_reproduce.sh  # fresh-copy re-run; must report MATCH
bash scripts/verify_digests.sh   # sha256sum -c SHA256SUMS
```

Requirements: Python 3 (standard library only), bash, sha256sum, diff.
No network access and no pip installs are needed to run the engine or the
measurement script.

## Reproduce

`scripts/run_all.sh` runs `scripts/measure.py`, then the engine into
`outputs/run1`, checks the generated reports against the committed
`protocols/*.md` reports, regenerates `findings.md` and `docs/index.html`
and diffs them against the committed files, runs the consistency checks,
and verifies digests. `scripts/clean_reproduce.sh` copies the pack
(excluding `outputs/` and `.git`) to a fresh directory, runs the full
pipeline there into `outputs/run2-clean`, and diffs it against
`outputs/run1`; it must report MATCH (byte-identical).

## Generated files and digests

- `docs/index.html` is generated from engine output by
  `scripts/build_docs.py`, so it is excluded from `SHA256SUMS` (this is
  stated in `framework/spec.md` section 7 as well).
- `outputs/` is generated by the scripts and is not covered by `SHA256SUMS`.
- `SHA256SUMS` covers every other pack file.

## Honest limitations

- Compound's Governor Bravo mainnet address remains unverified from a
  primary source (carried forward from v1.0.0; re-attempted this round).
- ENS per-delegate / top-holder concentration (HHI) was not measured;
  only the delegated share (3.98% of supply) is measured.
- The ENS Governor Nexus social vote total is reported as a displayed
  total only; no quorum verdict is drawn from it.
- EP 6.45 / EP 6.50 vote totals come from a secondary analysis that cites
  on-chain reads.
- Cosmos Hub historical turnout uses the snapshot-date bonded denominator;
  Proposal 1043 (39.72%) is borderline and no quorum verdict is drawn
  from it.
- The Cosmos Hub `proposal_cancel_ratio` semantics were not verified from
  a primary source.
- The engine scores documented parameters and observed proposals; it does
  not re-execute proposals on-chain.
